# Введение в ООП.

## Описание 
А данной работе созданы два класса: ```Product``` и ```Category```
Для классов определены необходимые атрибуты

### Описание модулей.
#### category
Для ```Category``` определены свойства ```name, description, products```

Доработан метод, который добавляет продукт в категорию таким образом, чтобы не было возможности добавить вместо продукта или его наследников любой другой объект.
#### products
Для ```Product``` определены свойства ```name, description, price, quantity```
Созданы два класса наследников класса ```Product```: ```Smartphone``` и ```LawnGrass```
Класс ```Smartphone``` расширен атрибутами: efficiency, model, memory, color
Класс ```LawnGrass``` расширен атрибутами: country, germination_period, color
Доработана функциональность сложения таким образом, чтобы можно было складывать товары только из одинаковых классов продуктов.
```Product``` наследуется от ```BaseProduct``` и ```PrintMixin```

#### base_product
Создан базовый абстрактный класс с именем ```BaseProduct```, который является родительским для классов продуктов.

#### print_mixin
Реализован класс-миксин ```PrintMixin``` который будет при создании объекта, то есть при работе метода 
```__init__```, печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
